# Media Control Extension

A lightweight browser extension that lets you control video and audio playback across multiple tabs from one simple interface.

## Features

- Control individual tab volume
- Play and pause media
- Mute and unmute tabs
- View media titles and website names
- Pause all and mute all
- Minimal dark-themed interface

## Installation

1. Download the repository as a ZIP.
2. Extract the ZIP file.
3. Open `brave://extensions` or `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.

## Supported Browsers

- Brave
- Google Chrome
- Other compatible Chromium-based browsers

## Limitations

Some websites using custom media players may not support all controls.
